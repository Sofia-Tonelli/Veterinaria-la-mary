## 1ra Entrega

Estructura base de la aplicación web con HTML y CSS, compuesta por 3 páginas:

- `index.html` — Inicio / Portada (incluye listado de veterinarios)
- `institucional.html` — Información institucional
- `contacto.html` — Contacto

Todas las páginas comparten el mismo menú de navegación y pie de página, y están enlazadas entre sí mediante rutas relativas.

## Cómo correr el proyecto

1. Instalar dependencias:
   ```
   npm install
   ```
2. Levantar el servidor de desarrollo con Vite:
   ```
   npx vite
   ```
3. Abrir en el navegador la URL que indique la terminal (por defecto `http://localhost:5173/`).
